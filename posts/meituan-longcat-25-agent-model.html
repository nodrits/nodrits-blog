A Food-Delivery Giant Built a 1.6 Trillion Brain: Meituan's LongCat-2.5

November 4, 2026 · Nodrits Solutions · 3 min read

A food-delivery giant built a 1.6 trillion brain. Meituan, the Chinese company best known for getting dinner to your door, made LongCat-2.5 generally available on November 2, 2026 — a frontier-scale model built for one job: keeping an AI agent productive across long, messy projects instead of single prompts.

What happened

According to Meituan's LongCat API platform changelog and the company's own pages, as covered by TechNode, Crypto Briefing, TheDevDrift and AI Weekly on November 2–3, 2026, LongCat-2.5 is a natively multimodal mixture-of-experts model with 1.6 trillion total parameters and roughly 48 billion activated per token. It offers a 1-million-token context window — enough to hold an entire codebase, multi-tab browser sessions and multi-stage workflows in working memory — and up to 128,000 tokens of output. It is aimed at long-horizon agentic work across terminals, browsers, GUIs, spreadsheets and design tools, following a preview released on September 25. The model is live through Meituan's chat service and API platform, which speaks both the OpenAI and Anthropic request formats, so it drops into an existing Claude Code or OpenAI-compatible harness by changing a base URL. Limited-time discounted pricing is $0.30 per million uncached input tokens, $0.006 per million cached input tokens and $1.20 per million output tokens. GitHub and Hugging Face releases of the weights are planned but have not happened — today the model is API-only.

Why it matters

Two things make this launch bigger than its spec sheet. First, Meituan says LongCat-2.5 was trained entirely on domestically produced Chinese AI accelerators, whose vendor it will not name — a frontier-scale model built without Nvidia hardware, inside the export-restriction regime that was supposed to make that hard. Second, the price: at $0.30 in and $1.20 out with a 1-million-token window, long agent runs become cheap to test, which is exactly the configuration sustained agent work bills against. The caveats matter as much as the claims. Meituan's benchmark positioning — between Claude Opus 4.8 and Opus 5, beating Opus 5 on some tests, beating GPT-5.6-Sol on 20 of 27 shared tests by one account — comes with no published benchmark tables and no independent evaluation yet, and much of the architectural detail people quote actually comes from the LongCat-2.0 report. Treat the capability claims as the company's until third parties verify them.

What it means for you

If you run agents, this is a cheap experiment with a clear test. Point an existing harness at the API, give it a real multi-step job — a codebase task, a browser workflow, a spreadsheet pipeline — and measure sustained performance, not a single prompt. The 1-million-token window and near-free cached input are genuinely useful for long runs, but do not plan production around benchmark claims until independent tests land, and do not assume self-hosting: with no weights released, you are renting, not owning. If your roadmap depends on Nvidia-only infrastructure, note the strategic signal too — the supply chain for frontier models just got wider.

The Nodrits take

The agent race has a new supplier, and it delivers dumplings. A delivery company shipping a frontier agent model says everything about where AI value now sits: not in who trains the biggest model, but in who makes long, autonomous work cheap and reliable.
