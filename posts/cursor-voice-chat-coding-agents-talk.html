Cursor's Coding Agents Learned to Talk — Voice Chat Arrives

November 8, 2026 · Nodrits Solutions · 3 min read

Cursor's coding agent just learned to talk. On November 6, 2026, Cursor shipped Voice Chat with Agents — a two-way realtime voice call with your coding agent. Describe a change out loud, ask what the agent is doing, and hear its progress while it keeps working.

What happened

Cursor announced Voice Chat with Agents in its November 6, 2026 changelog. It works in the Agents Window, the IDE, on the web, and in Cursor for iOS. When the agent is idle and the chat input is empty, you click the waveform button labelled Start voice chat — it sits where Send usually is, next to the microphone button for dictation. On iOS, you can also say “Hey Siri, call Cursor” to start a call with a new agent. The voice agent listens, replies, and hands coding work to the agent in your chat. While that agent runs, you can keep the conversation going: ask what changed in a diff, check on a run, search earlier messages and calls with this agent, or switch between workers in a project that has them. The coding agent also speaks for itself, sharing short progress notes while it works and a brief answer when it is done. Voice chat runs on Grok Voice, with selectable voices including Ara, Eve, Leo, Rex and Sal — and with Privacy Mode on, voice chat runs with zero data retention. It is separate from dictation, the older Voice Mode, which still turns speech into text in the chat input.

Why it matters

Coding is moving from typing to talking. A voice call turns the coding agent from a tool you type at into a partner you talk to — describe the change, hear the plan, and keep working while it runs. The split is deliberate and clever: Grok Voice handles the listening and speaking while the coding agent keeps the model you picked, so the voice layer never touches the code quality. The first tool to make pair programming with an AI feel like a real conversation wins a real workflow advantage — and Cursor just claimed it. The limits matter too: voice calls need a signed-in Cursor account, API-key sessions cannot start them, a daily call limit applies (Cursor has not published the number), and calls end after about ten minutes of silence with no work running.

What it means for you

Talk through a fix while you walk, and check diffs by ear while your hands stay on the keyboard. Use voice for describing intent and checking progress — the jobs talking is good at. Keep the review on screen: the voice agent can summarise a diff, but the diff itself still deserves your eyes before you accept it. If you work in a regulated environment, confirm the Privacy Mode policy first — zero data retention is the feature that makes voice safe to use on real code.

The Nodrits take
