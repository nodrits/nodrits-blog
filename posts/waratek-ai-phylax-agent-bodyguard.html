Waratek AI Phylax: A Bodyguard Inside the Runtime for AI Agents

October 27, 2026 · Nodrits Solutions · 3 min read

Your AI agent can be hijacked by a document — a poisoned instruction hidden in a file, a web page or a tool response can steer it into doing something it was never meant to do. Waratek's answer, launched October 26, 2026 at Oracle AI World in Las Vegas, is AI Phylax: a guard that lives inside the runtime and enforces security rules that cannot be rewritten while the agent runs.

What happened

Waratek announced AI Phylax on October 26, 2026, at Oracle AI World in Las Vegas. The product protects Java-based AI agents from application attacks while they run, applying the company's immutable-rule runtime protection to agents. Phylax takes its name from the ancient Greek word for guardian. It is aimed at organisations whose agents have moved from pilots into production, where they read emails, query databases, call APIs and act on behalf of employees and customers.

Why it matters

Agents are a new attack surface, and they are a strange one: the attacker does not need to breach the application at all. Prompt injection, tool hijacking and goal manipulation all work the same way — hide an instruction where the agent will read it, and the agent obeys it as if it were its own task. Filters that try to spot malicious text are probabilistic: they guess, and new phrasing can evade them. Waratek's argument is that security teams need deterministic controls that do not guess — rules enforced in the runtime, where an attempt to change the agent's behaviour is blocked before any compromise. As chair and CEO Doug Ennis put it: “The agent does what it was built to do, and nothing else.”

What it means for you

If you deploy agents, start with an inventory: which agents touch sensitive data or tools, and what exactly can each one do? Log every tool call end to end, test agents with hostile documents before production, and treat agent permissions the way you treat employee permissions — least privilege, reviewed regularly. A filter on the front door is not enough when the agent itself can be talked into opening it.
