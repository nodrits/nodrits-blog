Akamai Launches AI Inference and Agent Sandbox: A Boundary for AI Agents That Write Their Own Code

October 28, 2026 · Nodrits Solutions · 3 min read

Your AI agent writes its own code now — and runs it. Akamai's answer, launched October 27, 2026, is a boundary around that code: Akamai Inference, a managed service for serving models, and Akamai Agent Sandbox, an isolated execution environment where the code agents write runs under strict limits. The pitch is simple — agents need boundaries, not just brains.

What happened

Akamai (Nasdaq: AKAM) announced Akamai Inference and Akamai Agent Sandbox on October 27, 2026, from Cambridge, Massachusetts, as two foundational products for its AI stack on Akamai Cloud. Akamai Inference is a managed model-serving service for open-weight and custom models, offered through OpenAI-compatible APIs with serverless pay-per-use or dedicated deployments. Its launch catalog holds 12 open-weight models from 8 billion to 2.8 trillion parameters, including NVIDIA Nemotron 3 Ultra, OpenAI gpt-oss-120b and Google Gemma 4. Akamai Agent Sandbox isolates the code AI agents write and run: agents run on Akamai Functions, and their code executes in its own environment, separated from the agent runtime, with WebAssembly isolation limiting compute, memory, outbound connections and system capabilities. Both products are in beta at launch, and Akamai has not stated pricing.

Why it matters

Agents have crossed a line that makes infrastructure people nervous: they no longer just answer questions, they write code and execute it — code that can reach databases, tools and live systems. Most teams assemble the pieces themselves, from separate providers, and secure the seams by hand. Akamai's argument is that the sandbox belongs in the platform: one cloud, from dense GPU and CPU clusters in core regions to more than 4,350 edge locations, protected by the same security portfolio that defends many of the world's largest online businesses. The company says the foundation has already secured multiyear Akamai Cloud contracts collectively worth more than $14 billion. As Jon Alexander, Akamai's Senior Vice President of Cloud Technology, put it: “Every team running agents needs a boundary around the code those agents write.”

What it means for you

If you run agents anywhere near production, the rule from this launch applies whether or not you buy Akamai: sandbox every agent before it touches a live system. Give each agent only the tools and data its job needs, log every action and tool call end to end, test with hostile inputs before production, and never let an agent run unreviewed code against real accounts. The model is the easy part; the boundary is the work.
